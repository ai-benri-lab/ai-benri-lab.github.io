AI Benri Lab

AIナレーション付きの「便利グッズ紹介ショート動画」を制作し、クリエイター自身のTikTokアカウントへ下書き・投稿するための制作支援ツールです。

AI Benri Lab is a video-creation tool that generates narrated short product-review videos and uploads them to the creator's own TikTok account (as drafts or scheduled posts) via the TikTok Content Posting API.

What the app does / このアプリがすること

  • Generates a script and AI voice narration (VOICEVOX) for a product-review video.
  • Renders a vertical short video with captions.
  • With the creator's explicit authorization (TikTok Login Kit), uploads the video to the creator's own account using the Content Posting API. Every video is labeled as AI-generated content.
  • Reads basic profile info and the creator's own video statistics (views, likes, comments) to help improve future videos.

Operator / 運営者

AI Benri Lab is operated by an individual creator in Japan. Contact: GitHub @ai-benri-lab
